Explora GitHub Copilot a lo largo del ciclo de vida del desarrollo de software mediante escenarios realistas, una aplicación completa y un backlog compartido. Trabajarás de forma iterativa para planificar cambios, crear código, probar el comportamiento, revisar solicitudes de cambios y gestionar el trabajo con agentes.

## Escenario

Eres una persona desarrolladora nueva en Tailspin Toys, una empresa ficticia que ofrece financiación colectiva para juegos de mesa con un tema para desarrolladores. El backlog del equipo ya está creado como incidencias de GitHub, listas para que las resuelvas. Incluye funcionalidades como el filtrado y la paginación, además de mejoras de calidad como accesibilidad y estándares de programación.

## Elige tu entorno

GitHub Copilot está disponible en todos los entornos en los que trabajas. Elige el que mejor se adapte a tu forma de desarrollar. Cada taller empieza con su propia configuración y usa el escenario compartido de Tailspin Toys.

### [GitHub Copilot CLI][cli]

Usa el asistente con agentes en el terminal. Trabaja con los modos Plan y Autopilot, instrucciones, skills, agentes personalizados, Playwright MCP, Agent Merge y comandos de barra útiles.

### [Aplicación GitHub Copilot][app]

Ejecuta sesiones de agente en paralelo, cambia el modo de las sesiones, colabora en lienzos y gestiona incidencias y solicitudes de cambios de GitHub desde la aplicación de escritorio.

### [GitHub Copilot cloud agent][cloud]

Asigna incidencias de GitHub a un agente asíncrono, orienta su trabajo, supervisa el progreso y revisa las solicitudes de cambios que abre.

### [Visual Studio Code][vscode]

Usa GitHub Copilot en Visual Studio Code y GitHub Codespaces. Trabaja con el modo agente de Copilot Chat, servidores MCP y agentes personalizados sin salir del editor.

GitHub Copilot をエージェント モードにすると、コードベースを調べ、変更を提案し、ファイルを編集して、コマンドを実行します。VS Code の Copilot Chat では、ローカル マシン上でリアルタイムに行われる各ツール呼び出しやファイル編集を確認できます。差分をインラインでレビューし、変更を個別に採用または取り消して、エディターを離れずに追加プロンプトを送って作業を調整したり拡張したりできます。

この演習では、次のことを行います。

- アクセシビリティ エージェントの作業をリアルタイムで監視します。
- 提案されたファイル編集をレビューして採用します。
- セッション中にエージェントをガイドし、ハイ コントラストに加えてライト モードの切り替えを追加します。

## シナリオ

[演習 4][previous-lesson]で使ったアクセシビリティ カスタム エージェントは、ハイ コントラスト モードを実装しています。作業中にデザイン チームから追加の依頼がありました。既定のテーマが暗すぎると感じるユーザー向けに、ライト モードの切り替えも追加したいとのことです。新しい会話を最初から始める代わりに、既存のセッションをガイドして作業を拡張します。

## Copilot の進捗を監視する

Copilot Chat ビューには、エージェントが実行する各手順 (調査するファイル、実行するコマンド、提案する編集) が表示されます。ファイル編集は差分と **Keep** / **Undo** コントロールとともにインライン表示されます。

1. 演習 4 から Copilot Chat ビューに戻ります。
2. エージェントの作業中はチャットをスクロールし、ツール呼び出しを確認します。ファイルの読み取りや編集、実行を求められるターミナル コマンドが表示されます。
3. エージェントがファイルの編集を提案すると、差分がインラインで表示されます。
    - **Keep** を選択すると変更を採用します。
    - **Undo** を選択すると変更を取り消し、エージェントに再度作業させます。
4. チャット上部にある **Files changed** インジケーターを開くと、このセッションでエージェントが変更したファイル全体を確認できます。

> [!NOTE]
> ターミナル コマンドの実行など、ツール呼び出しで許可が必要な場合、エージェントは一時停止して **Allow** を表示します。許可するコマンドは慎重に選んでください。

5. エージェントがハイ コントラスト モードを実装し終えるまで待ちます。変更内容をまとめた最終メッセージが表示されます。

## エージェントにライト モードを追加するよう依頼する

ハイ コントラスト モードができたので、同じ会話を続けてライト モードの切り替えを追加します。同じチャット セッションを使うため、エージェントは前の作業から、変更したコンポーネント、使用したスタイル、設定した local storage のパターンなどのコンテキストを引き継ぎます。

1. Copilot Chat の入力欄に、次の追加プロンプトを送信します。

    ```plaintext
    Nice work! Now add a light-mode toggle alongside the high-contrast toggle. Light mode should follow the same pattern — persist via local storage and be accessible from the same area of the UI. The user should be able to enable high-contrast and light mode independently.
    ```

2. エージェントが既存の変更を調べ、ライト モードを追加する変更を提案します。
3. ハイ コントラスト モードのときと同じように、新しい編集を確認し、差分ごとに **Keep** または **Undo** を選択します。
4. エージェントの方向性が希望と異なる場合 (たとえばトグル UI を意図せずリファクタリングする場合) は、チャット入力欄の横にある **Stop** ボタンで停止し、明確な追加メッセージを送信します。

> [!TIP]
> 進行中のセッションをガイドすると、最初からやり直すより速く作業できます。追加プロンプトで調整を依頼できます (「CSS を簡潔にして、セレクターの重複ではなく CSS 変数を使ってください」)、方向を修正できます (「3 つ目のトグルを追加せず、既存の設定パネルにライト モードを追加してください」)、範囲を拡張できます (「両方のトグルにキーボード ショートカットも追加してください」)。

## 作業ファイルをレビューする

作業をコミットする前に、エージェントが変更したファイルを確認します。

1. VS Code の **Source Control** ビューを開きます。
2. 変更されたファイルの一覧を確認します。Astro コンポーネント、スタイル、関連テストなどが更新されているはずです。
3. 変更されたファイルをいくつか開き、差分を確認します。カスタム エージェントのアクセシビリティ パターン (ARIA 属性、キーボード操作、セマンティック HTML、local storage による設定の保持) が反映されていることを確かめます。
4. 問題がなければ、Source Control パネルで変更をステージしてコミットします。次のレッスンで公開します。

## まとめと次のステップ

Copilot Chat のエージェント モードで進行中のセッションを監視してガイドし、ファイル編集を確認して採用または取り消し、コンテキストを維持したまま追加プロンプトで作業を拡張しました。

このレッスンでは、次のことを確認しました。

- エージェントの作業をリアルタイムで監視する
- ファイル編集を個別に採用または取り消す
- 追加プロンプトで作業中のセッションをガイドする
